# Plan 01-03: Styling engine — theme, color transforms, fills, geometry, SVG shape rendering

**Objective:** Give the absolute-positioned boxes of 01-02 their visual fidelity (decision 21 tier "fully rendered"): the theme model (color scheme + font scheme), a complete color engine (scheme colors through `p:clrMap`, all common transforms), fill resolution (solid / gradient / pattern / picture) emitted as SVG `<defs>`, and a preset-geometry engine (common presets as real path data, exotic presets and `a:custGeom` approximated with bbox paths + `approx` diagnostics). Shapes render as inline SVG inside their `.pp-el` boxes; lines, dashes, and arrowheads included.

```js
export function resolveColor(node, ctx) -> string | null
// returns CSS color: '#rrggbb' or 'rgba(r,g,b,a)' when alpha < 100%; null for noFill/absent
```

`ctx` = `{ theme, diag }`. Resolution rules:
1. `a:srgbClr@val` → hex (validate `/^[0-9a-fA-F]{6}$/`; invalid → `diag.add('approx','invalid color '+val)` + return null).
2. `a:sysClr` → `@lastClr` if present, else the sysClr name map (`window` → `FFFFFF`, `windowText` → `000000`, others → null + approx diagnostic).
3. `a:schemeClr@val` → look up `ctx.theme.clrScheme[val]`; if missing, try mapping through `ctx.theme.clrMap` first (e.g. `tx1` → `dk1`, `bg2` → `lt2` — the clrMap direction: a scheme name that equals a clrMap *value* like `tx1` resolves through the map to the scheme slot `dk1`; implement as: `clrMap[val] ? scheme[clrMap[val]] : scheme[val]`).
4. `a:prstClr@val` → named-palette table for the ~15 Office preset colors (`black`,`white`,`gray`,`red`,`green`,`blue`,`yellow`,`cyan`,`magenta` + numeric variants); anything else → null + `approx` diagnostic.
5. Then apply every transform child, in document order. Exact math (displayed once, reused everywhere):

```js
function hexToRgb(h) { return [parseInt(h.slice(0,2),16), parseInt(h.slice(2,4),16), parseInt(h.slice(4,6),16)]; }
function rgbToHex([r,g,b]) { return [r,g,b].map(v => Math.max(0, Math.min(255, Math.round(v))).toString(16).padStart(2,'0')).join(''); }
function rgbToHsl([r,g,b]) { /* standard CSS Color 4 round-trippable conversion; returns [h in [0,360), s, l in [0,1]] */ }
function hslToRgb([h,s,l]) { /* inverse of the above */ }

// val attr is per-mille of 100% unless noted
// lumMod:  l = l * (v/100000)
// lumOff:  l = l + (v/100000)
// tint:    blend toward white:  c' = c * (v/100000) + 255 * (1 - v/100000)   (per channel)
// shade:   c' = c * (v/100000)
// satMod:  s = s * (v/100000)
// hueMod:  h = (h + (v/1000)) % 360     (hueMod val is 60000ths of a degree: v/1000 gives degrees)
// alpha:   final alpha = v/100000       (applies to the returned rgba)
// gray:    g = 0.21r + 0.72g + 0.07b    → [g,g,g]
// inv (inverse): c' = 255 - c
// gamma / invGamma: c' = 255 * (c/255)^2.2  and  c' = 255 * (c/255)^(1/2.2)
```

Unlisted transforms → `diag.add('approx', 'color transform '+name)` and continue (never throw). Final alpha via any applied `a:alpha` → return `rgba(r,g,b,a)`.

Emitted for every non-text-only `sp`/`cxnSp`/`graphicFrame` element inside its `.pp-el` box (the shape sits *behind* the text; `.pp-geom` is absolutely positioned to fill the box):

```html
<svg class="pp-geom" viewBox="0 0 W H" width="W" height="H" preserveAspectRatio="none"
     style="position:absolute;left:0;top:0;overflow:visible">
  <defs>${gradientDefs}${patternDefs}${markerDefs}</defs>
  <path d="${pathData}" fill="${fillAttr}" fill-rule="evenodd"
        stroke="${strokeColor}" stroke-width="${w}" stroke-dasharray="${dash}"
        stroke-linecap="${cap}" stroke-linejoin="round"
        marker-start="url(#...)" marker-end="url(#...)"/>
</svg>
```

Rules: no fill resolved → `fill="none"`; `flipH/flipV` on `a:xfrm` → wrap path in `transform="translate(W,0) scale(-1,1)"` / `translate(0,H) scale(1,-1)`; `compound` lines `dbl`/`thickThin`/`thinThick`/`tri` → emit two/three parallel strokes offset by ±width/3 + `approx` diagnostic (true compound geometry is out of scope); shadows/effects (`a:effectLst`) → ignored with one `approx` diagnostic per slide, not per shape (rate-limit: keep a `Set` of seen diagnostic messages in `rctx.diag` — implement `diag.addOnce(kind,msg,slide)` in this task, extending `src/pptx/context.js` with the one-liner `if (this.items.some(i => i.msg === msg && i.slide === slide)) return;`).
