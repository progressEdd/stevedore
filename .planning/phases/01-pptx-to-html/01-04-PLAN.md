# Plan 01-04: Text engine with inheritance, semantic text rendering, media, groups, connectors

**Objective:** Deliver the decision-21 "fully rendered" tier for text and pictures: the full `a:txBody` model with the placeholder inheritance chain (slide → layout → master + list styles), semantic HTML rendering (bullets as real lists, runs as styled `<span>`, fields, hyperlinks, autofit scale), picture fidelity (crop, data-URI media, SVG blips; EMF/WMF/TIFF → diagnostics), and geometric groups with child-coordinate transforms plus connectors.

**Standing rules** (same as prior plans): zero-dep, `node --test scripts/test/`, own code + MIT credit comments, EMU→px `/9525`. Interfaces from 01-01…01-03 (`XNode`, `resolveColor`, `resolveFill`, `resolveLine`, `fontFamily`, `Diagnostics.addOnce`) are fixed — build against them, don't reshape them.

```js
{
  bodyPr: {
    anchor: 't'|'ctr'|'b',              // default 't'
    insets: { l, t, r, b },             // px, defaults 91440/45720/91440/45720 EMU (0.1"/0.05")

    autofit: { fontScale: 1, lnSpcReduction: 1 },  // from a:normAutofit attrs /100000; a:spAutoFit -> flag
    vert: 'horz'|'vert'|'vert270'|'eaVert'|'mongolianVert'|'wordArtVert'|...,   // kept raw
    cols: number,                        // a:cols@num, default 1
  },
  paragraphs: [{
    pPr: { algn: 'l'|'ctr'|'r'|'just'|'justLow'|'dist'|'thaiDist',  // default null (inherit 'l')
           marL, indent,                // px
           lvl: number,
           bullet: { type: 'none'|'char'|'auto'|'pic', char?, startAt?, numType?, picPart?, size? } | null,  // null = inherit from chain
           lnSpc: { kind: 'pct'|'pts', v }, spcBef: {...}, spcAft: {...},   // pct v in 0..n (100000=100%), pts in px
           tabs: [{ pos, algn }] },
    runs: [{
      text: string,                     // a:t content (symbol fonts mapped BEFORE storage, see below)
      rPr: { sz: px, b, i, u: string, strike: 'noStrike'|'sngStrike'|'dblStrike', caps: 'none'|'small'|'all',
             baselinePct: number,        // @baseline /1000, e.g. 30000 -> 30%
             spc: px,                    // letter-spacing @spc /100 -> px (approximation, documented)
             color: string|null, highlight: string|null,
             font: { latin, ea, cs, sym },    // resolved typefaces; theme refs (+mj-lt etc.) resolved via fontFamily in render
             link: { url: string, jump: 'slide'|null } | null,   // a:hlinkClick r:id -> rels; ppaction:// -> jump
             outline: Fill|null, gradFill: Fill|null },           // kept for render; outline/grad -> approx diagnostics at render
      field: { type: 'slidenum'|'datetime'|null, fixed: string } | null,   // a:fld: type + a:t fallback text
    }],
  }],
}
```

**Inheritance chain merge** — the core of this task. Implement `mergeProps(levels)` where `levels` is ordered most-general → most-specific:

```
[ presentation defaultTextStyle (a:lvl1pPr… per paragraph lvl),
  master a:txStyles (bodyStyle/titleStyle/otherStyle, per lvl; selected by ph.type: title|ctrTitle -> titleStyle, else bodyStyle),
  master placeholder's txBody lstStyle + paragraphs' pPr (the ph-matched sp in the master layer),
  layout placeholder's txBody lstStyle + paragraphs' pPr (ph-matched in the layout layer),
  shape's own a:lstStyle,
  paragraph a:pPr,
  run a:rPr ]
```

Matching a placeholder in a layer: `ph.type` equal, or both `idx` values equal when type is `body`/null. Merge rule per property: first defined value from the most specific level wins; `a:buNone` in a specific level overrides an inherited `buChar`. Colors resolve through `resolveColor` *after* merge (theme transforms need final context). Autofit `fontScale` applies at render, not here. When the shape has no `p:ph`, skip the two placeholder levels (chain shortens to defaultTextStyle → lstStyle → pPr → rPr).

Symbol fonts: create `scripts/src/pptx/symbols.js` in this task (small — `export function mapSymbol(typeface, charCode) -> string`): a Wingdings/Symbol map covering the ~30 most common glyph codes (`F0E0`-range private-use → Unicode: e.g. Wingdings `F0FC` → `✓`, `F0FB` → `✗`, `F0A7` → `▪`, Symbol `F0B7` → `•`, arrows `F0D8/F0D9/F0DA/F0DB` → `↑↓→←`, etc.); unmapped → return the original char + `addOnce('approx', 'symbol glyph unmapped')`. Apply when `rPr.sym` typeface (or latin typeface) is `Wingdings|Symbol|Webdings`.

Create `scripts/test/text.test.mjs` with a fixture deck whose *layout* placeholder defines `buChar "•"` and `marL=228600` and whose slide placeholder only sets run color — assert the merged paragraph bullet comes from the layout level and the run color from the slide level (proves both directions of the chain). <name>Task 2: Render semantic HTML text — lists, runs, fields, links, autofit, vertical text</name>
<files>scripts/src/render/text.js, scripts/test/render-text.test.mjs</files>
<action>
Create `scripts/src/render/text.js`:

```js
export function renderText(textBody, element, rctx, opts) -> string
```

`opts = { slideIndex, slideCount, titleLevel }` (`titleLevel` 1 when element.ph.type ∈ {title, ctrTitle}, 2 for subtitle, 0 otherwise). Rendering rules — display, don't describe:

1. **Semantic containers** (decision 15): `titleLevel === 1` → `<h1>`; 2 → `<h2>`; else: consecutive paragraphs with `bullet.type ∈ {char, auto}` group into `<ul>` / `<ol start="${startAt}">` (auto → `<ol>`; `numType` ∈ {arabicPeriod, alphaLcParen, romanLcPeriod, …} → set `type` attr per the HTML mapping: `1`, `a`, `i`, `A`, `I`; unmapped → plain `1` + approx-once diagnostic); non-bulleted runs of paragraphs → successive `<p>` elements. Empty paragraph → `<p><br></p>` (PowerPoint blank lines must survive).
2. **Bullets**: `type:'char'` → `<li style="list-style:none">` with the char in a `<span class="pp-bu">` floated via `display:inline-block;width:${bulletBox}px` where `bulletBox = (marL + indent) px`; simpler exact approach — emit `<li style="list-style-type:none;padding-left:${marL - indent}px;text-indent:${-indent}px"><span aria-hidden="true">${bulletChar} </span>…`. `type:'pic'` → bullet char replaced by `<img class="pp-bu-img" src="${dataURI}" style="width:${size}px">`.
3. **Runs** — every property inline (no classes, output must be self-contained):

```html
<span style="font-size:${sz}px;font-family:${fontFamily stack};font-weight:${b?'700':'400'};
  font-style:${i?'italic':'normal'};color:${color};text-decoration:${underlineCss};
  ${caps==='small'?'font-variant:small-caps;':''}${spc?`letter-spacing:${spc}px;`:''}
  ${highlight?`background-color:${highlight};`:''}
  ${baselinePct?`vertical-align:${baselinePct}%;position:relative;top:${-baselinePct*0.4}px;`:''}">${text}</span>
```

Underline map (OOXML `u` attr → CSS `text-decoration`), all 18 variants: `none→'', sng→'underline', dbl→'underline double'` — wait, CSS has no double underline: `dbl` → `border-bottom:3px double currentColor` + `display:inline-block` + `text-decoration:none` — encode as `{ css: 'text-decoration:none;border-bottom:3px double currentColor' }`; `wavy*` → `wavy underline`; `dash*` → `dashed underline`; `dot*`/`dotted` → `dotted underline`; `dashLong*` → `dashed underline`; `heavy` suffix → also `text-decoration-thickness:2px` (best-effort, no diagnostic); `words` suffix → `text-decoration-line:underline` only (approx-once diagnostic: word-only underline not supported). Strike: `sngStrike` → `line-through`; `dblStrike` → `line-through double` where supported else `line-through` + approx-once.
4. **Fields**: `slidenum` → render `opts.slideIndex`; `datetime*` → render `fixed` text (the stored value in `a:t`); unknown → `fixed` + approx-once.
5. **Hyperlinks**: `link.url` → `<a href="${url}" ${url.startsWith('http')?'target="_blank" rel="noopener"':''}>` wrapping the run's span; scheme whitelist `http:, https:, mailto:` — anything else (incl. `javascript:`) → plain span + `approx` diagnostic (safety rule adapted from upstream `safeUrl`).
6. **Autofit**: `autofit.fontScale` → multiply every run's `sz` by `fontScale` at emit time; `lnSpcReduction` → multiply computed `lnSpc`.
7. **Paragraph spacing**: `lnSpc pct v=1` → `line-height:1.2` baseline? NO — exact: pct → `line-height:${v/100000}` where 100000 = 1.0; pts → `line-height:${v}px`. `spcBef/spcAft` → `margin-top/bottom:${v}px` (pct variant → `${v/100000}em`). Alignment map: `l→left, ctr→center, r→right, just→justify, dist→text-align-last:justify;text-align:justify` (+approx-once), `thaiDist/justLow` → `justify` + approx-once.
8. **Body-level**: container gets `display:flex;flex-direction:${cols>1?'row':'column'};${cols>1?`column-count:${cols};`:''}justify-content:${anchor map t:flex-start,ctr:center,b:flex-end};padding:${insets.t}px ${insets.r}px ${insets.b}px ${insets.l}px`;${wrap==='none'?'white-space:nowrap;':''}`. `vert` mapping: `vert→'writing-mode:vertical-rl'`, `vert270→'writing-mode:vertical-rl;transform:rotate(180deg)'`, `eaVert/mongolianVert→'writing-mode:vertical-rl'`, `wordArtVert*` and any other → horizontal + approx-once diagnostic.
9. ALL text through `escapeXml`; ALL font-family values quoted.

Rewire `scripts/src/render/slide.js` (modify): the 01-02 concatenated `text` is replaced by `renderText(buildTextBody(...), ...)` output inside each `.pp-el`; keep the `<h1>` semantic title behavior consistent (title boxes now get `<h1>` via `titleLevel`, not by special-casing in slide.js).

Create `scripts/test/render-text.test.mjs`: bulleted char list renders `<ul>` + `list-style-type:none` + the bullet char; numbered auto renders `<ol`; slidenum field on slide 3 of 5 renders `3`; underline `wavyHeavy` renders `wavy` + thickness; `fontScale 0.75` on a 32px run → `font-size:24px`; `javascript:` link → no `<a href`; vertical `eaVert` → `writing-mode:vertical-rl`.

<name>Task 3: Media fidelity — crop, SVG blips, unsupported formats; groups; connectors</name>
<files>scripts/src/pptx/slide.js, scripts/src/render/slide.js, scripts/test/media.test.mjs</files>
<action>
Modify `scripts/src/pptx/slide.js`:

1. **Picture crop** (`a:blipFill/a:srcRect`): store `image.srcRect = { l, t, r, b }` (per-mille ints, default 0).
2. **Groups** (`p:grpSp`): proper child-coordinate transform (adapted from upstream). For a group with `a:xfrm` off `(gx,gy)`, ext `(gw,gh)`, `chOff (cx,cy)`, `chExt (cw,ch)` (EMU → px first), every child element's box is remapped:

```js
// childX' = gx + (childX - cx) * (gw / cw);  childY' likewise;  childW' = childW * (gw / cw)
const kx = gw / cw, ky = gh / ch;
element.geom.x = gx + (element.geom.x - cx) * kx;
element.geom.y = gy + (element.geom.y - cy) * ky;
element.geom.w *= kx; element.geom.h *= ky;
```

Guard `cw/ch === 0` (use kx=1). Nesting: apply recursively — children of inner groups are remapped through the concatenated transforms (implement by passing a transform accumulator `{ kx, ky, dx, dy }` down the walk instead of mutating once). Group rotation: if the group has `rot`, wrap the whole group's emitted children in one container div with `transform:rotate()` — children keep their computed positions.
3. **Connectors** (`p:cxnSp`): treat as `sp` whose geometry is `line` (or its `prstGeom`); line fill from `a:ln` — task 01-03's `svgMarkers` already renders arrowheads; nothing new beyond ensuring `cxnSp` reaches the same shape path (it does via 01-02 dispatch — verify, and remove the placeholder diagnostic if one was left).
4. **Unsupported media** (decision 21 deferred tier): when a picture's part MIME is `image/x-emf`, `image/x-wmf`, `image/tiff`, or a font part `fntdata` — `diag.add('unsupported', 'image part X (EMF/WMF/TIFF) conversion deferred to a later phase')` and mark `image.unsupported = true`. OLE/ActiveX objects and ink (`p:graphicFrame` with `oleObject`/`p:pic` with ink content): `unsupported` diagnostic, no render.
5. **SVG blips**: `a:blip` with `a:extLst//asvg:svgBlip@r:embed` — prefer the SVG part over the raster fallback (namespace `asvg` = `http://schemas.microsoft.com/office/drawing/2016/SVG` — add it to the CANON map in `scripts/src/util/xml.js` as `asvg`).

Modify `scripts/src/render/slide.js`:
- Crop rendering via the object-fit trick (exact math — lift as written):

```js
// srcRect l/t/r/b per-mille (0..1000). CSS object-position percentage p maps so that p% of the
// container aligns with p% of the image; to show the crop window [l, 1000-r] × [t, 1000-b]:
const wl = 1000 - l - r, ht = 1000 - t - b;
const px = wl > 0 ? (l / wl) * 100 : 50;   // 0 when l=0
const py = ht > 0 ? (t / ht) * 100 : 50;
const style = `width:100%;height:100%;object-fit:cover;object-position:${px}% ${py}%`;
// the image is scaled up so the crop window fills the box: scale = max(1/wl, 1/ht) handled implicitly by cover
```

- `image.unsupported` → render the box with a dashed border + `alt="[image: EMF/WMF/TIFF deferred]"` so layout positions stay truthful.
- SVG blip parts: `url()` already returns `data:image/svg+xml;base64,…` via mime sniffing — no change needed beyond ensuring `svg` magic sniffing works (01-01 task 3).
