<task>
<name>Task 1: Parse p:timing and p:transition to plain JSON</name>
<files>src/pptx/timing.js, scripts/src/pptx/transition.js, scripts/test/timing.test.mjs</files>
<action>
Create `scripts/src/pptx/timing.js` (adapted from PPTX2HTML `scripts/src/pptx/timing.js`, MIT — parse yes, player no):

```js
export function parseTiming(timingNode, ctx) -> object | null   // p:timing root; null when absent
```

Parse to a plain-JSON tree — NO evaluation of formulas, NO behavior semantics; the tree is data for a future player (decision 22). Rules:
- Recursive walk producing `{ tag: canonicalName, attrs: {...all attrs as strings}, children: [...] }` for every element under `p:timing`, with two enrichments: (1) `spid` / `spid`-bearing attrs (`p:cBhvr//p:cTn@spid`? — actually `spid` appears as `p:spTgt@spid`) resolved to `{ spid: number }` kept as-is (numbers where `/^\d+$/`); (2) every `p:cTn` node gets `nodeType` passthrough from `@nodeType` (clickEffect/withEffect/afterEffect/mainSeq/tmSeq …) so sequencing is readable without interpretation.
- Cap: if the tree exceeds 20,000 nodes, stop and return `{ truncated: true, ... }` + `diag.add('approx', 'timing tree truncated')`.
- `p:bldLst` included as-is.

Create `scripts/src/pptx/transition.js` (adapted from PPTX2HTML `scripts/src/transition.js`, MIT):

```js
export function parseTransition(cSldParentNode, ctx) -> Transition | null
// p:transition child of p:sld: { type: <child element local name: 'fade'|'push'|'wipe'|'cover'|…>,
//   attrs: {...}, advClick: boolean|null, advTm: number|null, p14: { dur: number|null, extra: attrs }, known: boolean }
```

`known` = the child's local name is in the KNOWN set — include this exact list (from upstream): ` blinds, checker, circle, comb, cover, cut, diamond, dissolve, fade, newsflash, plus, pull, push, random, randomBar, split, strips, wedge, wheel, wipe, zoom, vortex, switch, flip, ripple, honeycomb, prism, doors, window, ferris, gallery, conveyor, pan, glitter, warp, flythrough, flash, shred, reveal, curtains, wind, fracture, pageCurl, airplane, origami, fallOver, morph`. Unknown → `known:false` + `diag.addOnce('approx', 'transition <name> recorded but not interpreted')` — recorded, never played.

Embedding (this task also touches `scripts/src/render/document.js` — one small addition): per-slide JSON rides the slide div:

```html
<script type="application/json" class="pp-timing-json">{"timing":…,"transition":…}</script>
```

placed INSIDE each `.pp-slide` div (document-level: slides keep their own data; `JSON.stringify` output must be HTML-safe — use `.replace(/</g,'\\u003c')`).

Create `scripts/test/timing.test.mjs`: fixture slide with a hand-built timing tree matching the dom-to-pptx shape documented in research (a `p:par/cTn@nodeType=clickEffect` containing `p:childTnLst/p:par` with `p:cBhvr` + `p:spTgt@spid="4"`); assert the JSON round-trips (`JSON.parse` of the embedded script reproduces `nodeType:'clickEffect'` and `spid:4` as a number), `<` in any string is escaped as `\u003c` (test with a title containing `<`), and `p:transition` of type `morph` yields `known:true`. An unknown transition `warp7` → `known:false` + one approx diagnostic.
