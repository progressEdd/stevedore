<task>
<name>Task 1: Write the zero-dep deck comparator scripts/compare-decks.mjs</name>
<files>scripts/compare-decks.mjs, test/compare.test.mjs</files>
<action>
Create `scripts/compare-decks.mjs` — pure-node structural comparison of two HTML decks (no DOM, no deps):

```
Usage: node scripts/compare-decks.mjs <source.html> <converted.html>
```

Behavior:
1. **Slide split**: in the source, slides are the top-level slide containers — Marp decks: `<section …>` blocks; our output: `<div class="pp-slide" …>` blocks. Implement `splitSlides(html)` returning arrays per deck: extract container blocks with a small brace-free scanner (find `<section` … matching `</section>`; `<div class="pp-slide"` … `</div>` — count nested `<div`/`</div>`), deep enough for these two shapes; strips `<script>`/`<style>` blocks first so markup noise cannot enter text.
2. **Text extraction**: strip all tags, collapse whitespace, split into word lists per slide (`\w`-and-beyond: split on whitespace, strip punctuation edges, lowercase).
3. **Metrics per slide pair**: Jaccard similarity `|A∩B| / |A∪B|` on word multisets (count-aware: use min(countA,countB) for ∩, sum for ∪). Report: slide counts, per-slide Jaccard, mean, min. Image counts (`<img` + `data:image` occurrences) per deck — report-only.
4. **Gates** (exit 1 on failure, message to stderr):
   - slide counts equal (after dropping source slides that contain no text AND no images — Marp section-split background containers can inflate counts; report dropped ones);
   - mean Jaccard ≥ **0.70**; min per-slide Jaccard ≥ **0.30** (code-block slides legitimately drift — tokenized syntax highlighting loses/gains words through the pptx round trip);
   - converted deck has ≥ **50%** of the source's image count.
5. Output human-readable table + `PASS`/`FAIL` line to stdout; exit 0/1.

Create `test/compare.test.mjs`: two tiny synthetic HTML strings (a `<section>` deck and a `<div class="pp-slide">` deck with identical text) → PASS, mean 1.0; one word changed on every slide → still PASS with mean < 1; slide count mismatch → FAIL exit 1 (test via importing the module's functions AND one `spawnSync` CLI run asserting exit codes). Script must be importable: `export function splitSlides(html)`, `export function words(slideHtml)`, `export function jaccard(a, b)` — put the `main()` behind `if (import.meta.url === pathToFileURL(process.argv[1]).href)`.
</action>
