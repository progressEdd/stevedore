# Plan 02-02: Fix the mergeProps cascade inversion in the text engine

**Objective:** Fix the deck-wide text-fidelity bug found by phase-02 research (02-RESEARCH.md Q2): `mergeProps` in `scripts/src/pptx/text.js:39–47` iterates the property cascade most-specific-first but *overwrites* unconditionally, so the **least**-specific level wins — the presentation's `p:defaultTextStyle` (`sz="1800"` → 24 px, `+mn-lt` → Calibri, scheme tx1 → black) clobbers every run's own `a:rPr`. All 800/800 spans currently render as `font-size:24px; font-family:"Calibri", Calibri, sans-serif; color:#000000`. This one fix deflates formatting drift on every slide at once (research recommendation step 1). It is our code, on the stevedore branch, per the phase constraint; the vendored `vendor/PPTX2HTML/src/pptx/text.js` (present after plan 02-01) is the reference for the correct first-defined-from-most-specific semantics.

**Standing facts:** same as 02-01 (bun not npm; `node --test scripts/test/*.test.mjs` glob form; test data at `../../00-supporting-files/data/land-e-tests/` from any `02-worktrees/*` worktree; commits atomic with subject prefix `(02-02): …`). Research probe (stevedore @ 3388fcd): `buildTextBody` without `defaultTextStyle` in ctx → `{sz:19, color:'#1f2328', font:{latin:'-apple-system'}}`; with it → `{sz:24, color:null, font:{latin:'+mn-lt'}}` — after this plan the "with it" case must produce the "without it" values.

**The edit** — in `scripts/src/pptx/text.js`, replace the body of `mergeProps` (currently lines ~39–47). Current (buggy):

```js
export function mergeProps(levels) {
  const out = {};
  for (let i = levels.length - 1; i >= 0; i--) {
    for (const [k, v] of Object.entries(levels[i] ?? {})) {
      if (v !== undefined) out[k] = v;
    }
  }
  return out;
}
```

Fixed (levels stay ordered most-general → most-specific; iterate most-specific first; FIRST set wins):

```js
export function mergeProps(levels) {
  const out = {};
  for (let i = levels.length - 1; i >= 0; i--) {                            // most specific first
    for (const [k, v] of Object.entries(levels[i] ?? {})) {
      if (v !== undefined && out[k] === undefined) out[k] = v;              // (02-02) first set wins
    }
  }
  return out;
}
```

The doc comment above the function already states the intended rule ("The most specific defined value wins per property") — it becomes true. One behavioral note to preserve: a specific level's `{ type: 'none' }` bullet still defuses an inherited `buChar` (whole-value first-set-win keeps that). Cross-check the semantics against `vendor/PPTX2HTML/src/pptx/text.js` if any doubt arises.

**Regression tests** — append to `scripts/test/text.test.mjs` (add `mergeProps` to the existing import from `../src/pptx/text.js`):

```js
test('mergeProps: most specific level wins — cascade inversion regression (02-02)', () => {
  assert.deepEqual(mergeProps([{ sz: 24 }, {}, { sz: 19 }]), { sz: 19 });
  assert.deepEqual(
    mergeProps([{ font: { latin: '+mn-lt' } }, { font: { latin: '-apple-system' } }]),
    { font: { latin: '-apple-system' } });
  assert.deepEqual(
    mergeProps([{ bullet: { type: 'char', char: '•' } }, { bullet: { type: 'none' } }]),
    { bullet: { type: 'none' } }); // specific buNone still defuses inherited buChar
});

test('defaultTextStyle fills gaps only — run a:rPr wins over presentation defaults (02-02)', () => {
  const base = load({
    defaultTextStyle:
      '<a:lvl1pPr><a:defRPr sz="1800"><a:solidFill><a:schemeClr val="tx1"/></a:solidFill>' +
      '<a:latin typeface="+mn-lt"/></a:defRPr></a:lvl1pPr>',
    slides: [{
      rels: [],
      texts: [{ paragraphs: [{ runs: [{
        t: 'styled',
        rPr: '<a:rPr sz="1414" b="1"><a:solidFill><a:srgbClr val="1F2328"/></a:solidFill>' +
             '<a:latin typeface="-apple-system"/></a:rPr>',
      }] }] }],
    }],
  });
  const el = base.slide.elements.find(e => e.layer === 'slide');
  const run = bodyOf(base, el).paragraphs[0].runs[0];
  assert.equal(run.rPr.sz, 19);                     // 1414 hundredths-pt → 19 px (run beats default 24)
  assert.equal(run.rPr.b, true);
  assert.equal(run.rPr.font.latin, '-apple-system');
  assert.equal(run.rPr.color, '#1f2328');           // resolved AFTER merge, from the run's own node
});
```
