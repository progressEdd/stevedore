# Plan 02-04: Redefine the comparator's image metric to media survival counting

**Objective:** Roadmap SC5, decision 9: replace the comparator's raw img-tag ratio gate (which demonstrably lies — it read 233% from junk gradient strips while the real photos were missing) with **survival counting**: every unique real media file referenced by the source deck (`src="…"` file paths — for LAND.E exactly 15: 10 raster/svg + 3 `.mp4` + 2 more pngs) must be present, byte-identical, in the round-trip output; the bar is 15/15. "Present in the output" means the file's exact bytes appear as an embedded `data:(image|video|audio)/…;base64` payload (or a resolvable file ref) in the converted HTML — our converter inlines media as data URIs via `rctx.url()`, so source bytes embedded by dom-to-pptx survive the whole loop verbatim. Decision 9 supersedes decision 5's earlier "≤100% over" phrasing: the raw count stays as a report-only line, the survival gate is the acceptance metric. This plan changes the gate only; reaching 15/15 on LAND.E is plan 02-05's work.

**Standing facts:** same as 02-01 (`node --test scripts/test/*.test.mjs` glob form; test data at `../../00-supporting-files/data/land-e-tests/`; commits atomic with subject prefix `(02-04): …`). The comparator is `scripts/compare-decks.mjs`, pure Node, importable (`splitSlides`, `words`, `jaccard`, `countImages` exported; `main()` behind the direct-run guard). Its current gates: slide counts equal, mean Jaccard ≥ 0.70, min ≥ 0.30, converted ≥ 50% of source image count (`IMAGE_RATIO_THRESHOLD`). The LAND.E source refs resolve relative to `reference/slides.html` (all 15 verified present on disk by research).

```js
// ---- media survival (phase 02, decision 9) ----------------------------------
// The acceptance image metric: each unique real media FILE referenced by the
// source (src="…" paths — not data URIs, not remote URLs) must survive into
// the converted deck byte-identically, as an embedded base64 payload or a
// resolvable file ref. Raw img-tag counting stays report-only above; it
// over-counted junk rasterizations while real photos went missing (233%).

const md5 = (buf) => createHash('md5').update(buf).digest('hex');

// unique non-data, non-remote src values of a deck (file refs)
export function mediaRefs(html) {
  const refs = new Set();
  for (const m of stripScriptStyle(html).matchAll(/\bsrc="([^"]+)"/g)) {
    const v = m[1];
    if (!/^(data:|https?:|blob:|#)/.test(v)) refs.add(v);
  }
  return [...refs];
}

// fingerprint set of media payloads reachable from a deck: embedded data URIs
// (any image/video/audio mime) plus file refs resolved against the deck's dir
export function mediaFingerprints(html, baseDir) {
  const fps = new Set();
  for (const m of stripScriptStyle(html)
    .matchAll(/data:(?:image|video|audio)\/[\w.+-]+;base64,([A-Za-z0-9+/=]+)/g))
    fps.add(md5(Buffer.from(m[1], 'base64')));
  for (const ref of mediaRefs(html)) {
    try { fps.add(md5(readFileSync(resolve(baseDir, ref)))); } catch { /* unreadable ref counts as missing */ }
  }
  return fps;
}

// how many of the source's referenced media files survive into the converted
// deck, and exactly which paths are missing
export function mediaSurvival(srcHtml, srcPath, convHtml, convPath) {
  const refs = mediaRefs(srcHtml);
  const convFps = mediaFingerprints(convHtml, dirname(convPath));
  const missing = [];
  for (const ref of refs) {
    let fp;
    try { fp = md5(readFileSync(resolve(dirname(srcPath), ref))); }
    catch { missing.push(ref); continue; }          // source ref itself unreadable
    if (!convFps.has(fp)) missing.push(ref);
  }
  return { expected: refs.length, survived: refs.length - missing.length, missing };
}
```
