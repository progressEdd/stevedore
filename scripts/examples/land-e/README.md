# Example: LAND.E deck (20 slides)

Real-world round trip: Marp HTML → dom-to-pptx → `deck.pptx` → this converter → `deck.html`.

Reproduce: `node scripts/pptx-to-html.js scripts/examples/land-e/deck.pptx -o scripts/examples/land-e/deck.html`
(run from the skill root). `deck.html` is self-contained — open directly in a browser.
